# `play` name-entry and results-loop control flow

The current production `play` body is synthetic and gated from recovered-game linking. This experiment changes only the retained evidence candidate `docs/attempts/game-main/play-merged.c`; it does not promote or integrate `play`.

Three current-source historical-order probes isolate the `run_demo` regression. `takeover-new-game-order-only-20260923` and `takeover-new-game-draw-only-20260923` keep `run_demo` as `FUNCTION_MATCH`. `takeover-new-game-play-only-20260923` changes its unchanged body and reports `DIFFER`, as does the combined `draw_frame`/`play` probe. The changed register at `run_demo` offset 52 and the one-byte shift at 73 are a downstream compiler-context witness; no `run_demo` body edit is justified.

Original `play` offsets 12015–12093 call `get_rank_id`, compute `(rank_id + 0x4a) << 4`, initialize the name-entry cursor, rank Y, scroller Y, and write 20 to the `done` stack slot before entering the loop at offset 12121. At offset 12108 the loop tests that slot for zero. The candidate initialized the counter to zero before the loop, tested it against 20, and put the other setup writes inside the later rank-change branch at original offset 12333. `takeover-play-rank-setup-20260923` moved the setup before the loop and changed the exit test to zero. The historical-order `play` candidate compiled to 16,699/17,420 bytes; `new_game` remained a strict function match and `run_demo` remained different. The candidate was 16,767 bytes before this experiment. The smaller size is not a reason to restore the unsupported control flow.

Original offsets 11863–11880 load the float literal at `0x4d6d84` (read-only PE bytes `00 00 0c 43`, exactly `140.0f`), compare it with local `hy` at `-0x934(%ebp)`, and jump back while `hy > 140.0f`. The candidate's `ply[player_id]->shake == 0 && falling > 0` exit was unsupported. `takeover-play-height-exit-20260923` replaces it with `hy <= 140.0f`; the candidate becomes 16,852/17,420 bytes. `takeover-play-height-combined-20260923` confirms that in the current combined historical-order context, `new_game` still matches strictly and `run_demo` still differs. No production recovery status changed.
